Started working on the new portfolio site today. Decided to use Zola because it's fast and simple.

No JavaScript frameworks, no build complexity - just clean HTML and CSS. The goal is to have something that loads instantly and works everywhere.

## What I'm Building

A simple portfolio site with:
- Clean, dark theme design
- Responsive layout
- Fast loading times
- Easy content management

## Tech Stack

- **Zola** for static site generation
- **Tailwind CSS** for styling
- **Markdown** for content
- **GitHub Pages** for hosting

This should be much simpler than the previous setup while maintaining the same visual design.
